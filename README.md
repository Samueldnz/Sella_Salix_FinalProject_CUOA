## 🏛️ Executive Summary / Sintesi del Progetto

**Nexofarm** is a strategic joint venture and life sciences digital platform created to evaluate the merger of two industrial champions located in the province of Vicenza (Veneto, Italy):
1. **Laboratorio Chimico Farmaceutico A. Sella S.r.l. (Schio, VI · Est. 1920):** Over a century of pharmaceutical heritage, official AIFA/GMP licenses, galenic formulations, and clinical trust.
2. **Salix S.r.l. (Monte di Malo, VI · Est. 1998):** Over 25 years of high-capacity contract development and manufacturing (CDMO) in food supplements, nutraceuticals, and medical devices across an automated facility exceeding 10,000 m².

Conceived during the summer exchange program at **CUOA Business School**, the project demonstrates how century-old Italian pharmaceutical tradition can synergize with modern biotechnology to capture the exploding European **Dermocosmetics** and **Nutricosmetics (Beauty-from-Within)** markets.

## 📊 Key Highlights & Market Realities

- **Comprehensive Market Analysis:** Complete bilingual report available in [`MARKET_ANALYSIS_SELLA_SALIX_NEXOFARM.md`](./MARKET_ANALYSIS_SELLA_SALIX_NEXOFARM.md).
- **The Italian Cosmetic Hegemony:** Over 60% of the world's premium cosmetics are manufactured in northern Italy (€18B turnover in 2025, €8.6B export).
- **The #1 European Nutraceutical Market:** Italy leads Europe in dietary supplement sales (€5.4B TAM, ~26% European share), with 78% sold through pharmacies requiring deep medical credibility.
- **The "In & Out" Care Synergy:** Combining Sella's clinical topical dermocosmetics with Salix's systemic oral nutricosmetics under one scientific governance.

## ✨ Features & Architecture

- **Bilingual Core (English & Italian):** Instant, zero-reload language toggle (`[EN | IT]`) persisting preferences in `localStorage` and synchronizing HTML document attributes.
- **Modern Traditional Italian Design:** Visual hierarchy marrying classic editorial Italian typography (**Cormorant Garamond** & **Cinzel**) with crisp biotechnology sans (**Plus Jakarta Sans**), warm Vicentine marble backgrounds, and Venetian crimson accents.
- **Dedicated Heritage & Synergy Section:** Interactive narrative detailing Sella (1920) and Salix (1998) profiles and academic origin at CUOA Business School.
- **Certifications & Governance Strip:** Showcasing AIFA, GMP, ISO 22716 (Cosmetics), ISO 9001, ISO 13485 (Medical Devices), and Cleanroom Grade C/D.
- **Full Legal & Privacy Compliance:**
  - **Informativa sulla Privacy (Privacy Policy):** Full GDPR (Articles 13 & 14) disclosure with DPO contacts, legal bases, and supervisory authority appeal rights.
  - **Informativa Estesa sui Cookie (Cookie Policy):** Compliant with the Italian *Garante per la protezione dei dati personali* Guidelines of June 10, 2021.
  - **Interactive Cookie Consent Center:** Granular preference manager with equal visual prominence for "Accept" and "Reject Non-Essential".
  - **Termini e Condizioni d'Uso (Terms of Use):** Intellectual property protection, scientific B2B disclaimers, and exclusive jurisdiction of the Court of Vicenza (*Foro di Vicenza*).
- **Technical SEO & Web Standards:** `robots.txt`, XML `sitemap.xml`, OpenGraph/Twitter Cards, multilingual `hreflang` alternates, and JSON-LD `Schema.org` `MedicalOrganization` structured data.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
```bash
# Clone repository
git clone git@github.com:Samueldnz/Sella_Salix_FinalProject_CUOA.git
cd Sella_Salix_FinalProject_CUOA

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build & Linting
```bash
# Run ESLint validation
npm run lint

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
